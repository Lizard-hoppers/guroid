# Gambling Community Bot

Telegram-бот анкеты для доступа в Private Gambling Community
([@GamblingCommunitybot](https://t.me/GamblingCommunitybot)).

## Флоу (7 блоков ТЗ)
1. Приветствие → «Получить доступ».
2. Вертикаль (8) → Грейд (6, у Gambling +«Инвестор») → Должность
   (свой список под пару вертикаль+грейд, +«Другое», +«Назад», пагинация).
   Инвестор-ветка (только Gambling): тип → суммы → что ищет (чекбоксы).
3. «Что наиболее актуально?» (свободный текст).
4. Имя. 5. Компания. 6. LinkedIn (+«Пропустить»).
7. Завершение → «Вступить в сообщество».

Каждая анкета → SQLite + (когда настроена) строка в Google Sheets + уведомление админам.

## Второй уровень: капча в группе + меню-ссылки после неё
Бот-админ группы при входе новичка мутит его и присылает капчу ОДНИМ сообщением: видео
сверху + приветствие с упоминанием ENG/RU со ссылками на главные чаты + пример
«A + B = ?» и кнопки-ответы (один верный). Неверный ответ — то же сообщение получает
новый пример, пользователь остаётся в муте (никого не кикаем/баним; капча бесконечна).
Верный ответ — размут, и **то же сообщение** (видео остаётся) редактируется: капча
убирается, вместо вариантов ответа появляются **5 инлайн-кнопок-ссылок** (Terms,
GuroPSP, GuroAffiliate, iGamingSchool, Collaboration) — сообщение не удаляется, остаётся
в чате памяткой со ссылками. Тексты/ссылки/видео/кнопки — всё правится в `/admin`
(«Тексты», «Медиа», «🔗 Меню группы»). См. `OPERATIONS.md`.

## Запуск локально
```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env   # заполнить BOT_TOKEN и пр.
.venv/bin/python bot.py
```
